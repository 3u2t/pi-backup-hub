Google meldet Messwerte mit einigen Minuten Verzögerung. Drive zeigt den zuletzt gemeldeten Minutenwert; Google Fotos die Summe des aktuellen Google-Kontingenttags. Tageslimits werden um Mitternacht US-Pazifikzeit zurückgesetzt. Fehlende Messwerte werden als „—“ angezeigt.

Einrichtung der Verbrauchsanzeige

Im selben Google-Projekt müssen die Cloud Monitoring API ↗ und die Service Usage API ↗ aktiviert sein. Danach „Live-Anzeige verbinden“ wählen und den heruntergeladenen Anmeldehelfer auf diesem Computer mit Python öffnen. Das Google-Konto muss die Projektmesswerte und Kontingente lesen dürfen.

Die Anzeige aktiviert keine Abrechnung und legt keine kostenpflichtigen Cloud-Ressourcen an. Google stellt monatlich eine Million abgefragte Messreihen pro Abrechnungskonto kostenlos bereit; diese Freimenge wird mit anderen Monitoring-Abfragen geteilt.

1. Eigenen Google-Client vorbereiten

Noch nicht eingerichtet

Dein Handy-Konto kann so bleiben. Die Anmeldung erfolgt einmal auf einem Computer mit dem Google-Konto, dessen Speicher du verwenden möchtest.

Anleitung für die Google-Client-Datei
  1. Öffne die Google Cloud Console und erstelle ein eigenes Projekt, zum Beispiel „Pi Backup Hub“.
  2. Aktiviere in diesem Projekt die Google Drive API und die Photos Library API.
  3. Richte unter „Google Auth Platform“ den Zustimmungsbildschirm für deine eigene App ein. Falls das Projekt im Testmodus ist, füge dein gewünschtes Google-Konto als Testnutzer hinzu.
  4. Erstelle unter „Clients“ einen OAuth-Client vom Typ Desktop-App und lade dessen JSON-Datei herunter.
  5. Wähle diese Datei unten aus. Sie wird ausschließlich in deiner Backup-App gespeichert. Für Drive wird nur Zugriff auf Dateien angefordert, die diese App selbst erstellt.
  6. Für den dauerhaften Betrieb muss die Google-App passend freigegeben sein. Im OAuth-Testmodus können Freigaben nach sieben Tagen ablaufen. Eventuelle Prüfungen und Zugriffsbeschränkungen zeigt Google im Projekt an.
